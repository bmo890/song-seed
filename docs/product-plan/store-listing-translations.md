# Store listing — translations

The English source is `store-truth.md` §6 (2026-11-14 copy). These follow it line for
line and use the app's own names for every feature (the locale files and
`docs/i18n/glossary-*.md`), so a listing never names a tool the app calls something
else. Written 2026-11-14; no native reader has checked them yet.

Where they go:
- **Play:** "Manage translations → Add your own translations" on the default listing.
  Spanish goes in twice, es-419 and es-ES, same text (the app speaks neutral Spanish).
  German de-DE, Portuguese pt-BR, Hebrew iw-IL. Title stays `SongNook`; graphics fall
  back to the English ones.
- **Apple:** with the next iOS version (an approved version's description is locked).
  Spanish (Mexico) and Spanish (Spain), German, Portuguese (Brazil), Hebrew. Apple's
  description swaps the backup line and appends the subscription paragraph, both given
  per language below.

Counts are checked: subtitle ≤ 30, short description ≤ 80, promotional text ≤ 170,
keywords ≤ 100, description ≤ 4000.
