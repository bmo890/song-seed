# Founder's answers to the feature ledger (2026-11-14)

Pasted by the founder from the form's "Copy my answers". Notes are their words, unedited.
The note "test" on decision 1 was Claude's own check of the form, not the founder's.

## Decisions (1 to 19)

All nineteen: **Agree** with the suggestion on the page. Notes:

- **3. Three-workspace limit has side doors.** "agree but if the user is exporting his
  workspace, deleting the in-app copy, opening a new 3rd workspace, then importing the one
  he just deleted in order to get around it and have 4 workspaces, that is a cheap
  workaround on the user and it should be blocked, im all for allowing htem to import a
  workspace from someone else (implies collaboration which we want to promote!) but is
  there a way to see a metadata stamp of who made the workspace and block it for him? is
  this getting too much in the details and not worth worrying about? im also concerned if
  3 workspaces for free users is too generous. we want to provide easy organization which
  was the original main point of the app, but is 3 too many? if someone has solo work and
  is in one band, thats 2 workspaces most likely, is it worth it to keep it at 3? i want to
  allow organization and not feel like users are getting 'pushed' into having to buying
  pro, i want them to see the usefullness of it and want it themselves, but i wonder if
  theyll never see the point if 3 is too generous"
- **19. Speed is free to hear and Pro to keep.** "and also users might get around it by
  clicking the "keep" button within full player. we dont want them to do that. otherwise
  its functionally the same as saving a copy. we want them if they are going to change the
  speed every time, to have to do it new when they open the full player, instead of it
  being 'saved' for the. actually weren't we talking about all practice tools being paid
  only? what do we think about that? we need to talk about the practice tools a bit i
  think"

## Paid lines (1 to 14)

Agree: Layers, Pins (free), Pitch, Step up, Editor Speed & pitch, Transpose and capo, Chart
books and setlists, Chart as PDF, Move an archived workspace to Files (off the list), Tempo
detection (off the list).

- **Workspaces: Do it differently.** "see my earlier comment about the number of workspace
  limits - we need to discuss what the right number is"
- **Word Finder: Do it differently.** "actually i think the word finder since we are using
  an api, and this is a bonus writing tool like wordspark, maybe we should consider making
  it all paid only. the majority of users will most likely only be using rhymes, is it
  better to keep it free to have them use the app more consistently instead of using
  dictionary.com etc, or charging them pro to use it? whats the best decision?"
- **Word games: Do it differently.** "free gets not 3 tries of each game, that would be 9
  free lyrics sparks. they should get 3 games, 1 per each type (thres 3 types of lyric
  sparks games currently). make sure that once someone has deleted one that they made, the
  number doesnt go down. pro of course gets no limit. what do you think?"
- **SongNook Send: note only.** "i thought free gets 3 links ever total? does it reset
  every month for them? i dont like that, they should get either a fixed number until
  theyre pro, or 1 every month. what do you think? trying to balance promoting using the
  app with gently pushing users to pay for pro without strong arming them"

## Anything else

"overall though i went through this list, i want to think with you what to do. i want to
make sure to be able to nudge people to buy pro but i dont want them feeling like im strong
arming them and being cheap. on the other hand im worried that theres not enough reason why
anyone would need to buy pro right now. i thought that the practice tools ere going to be
paywalled, and now it looks like thats not what we are wanting to do. i think that we need
to reconsider that. im wondering overall what does our pro plan actuall offer the user in
terms of benefits for dollar spent."

## Settled by these answers (not built yet)

Pins free everywhere (1). Leave the layer-combine workaround (2). Count a word game try only
once something is written (4). Flip the Send server switches on launch day (5). Going back
toward the original pitch, capo or key is always free (6). PDF stays Pro; correct the terms
(8). Capo in the recorder stays as it is (9). A kept friend's song stays as it is (10).
Export for DAW becomes Pro (11). Layer mixer, tempo changes and the daily companions stay
free (12, 13, 14). Send from a computer stays inside the free allowance (15). Tempo
detection and archive offload come off every Pro list (16, 17). Step up: nobody free can run
a drill, built-in or their own (18, and the "Ready drills" note).

## Still open (founder asked to think it through)

The practice tools as a whole (speed, loop, Keep); the free workspace count and the
export-and-import workaround; the Word Finder (all Pro, or Rhymes free); word games (one
try per game instead of three); Send (one link a month, or a fixed number ever); whether
Pro gives enough for the money.
